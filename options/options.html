多维表格信息

从多维表格 URL 中获取：
· 独立表格：https://xxx.feishu.cn/base/bascnXXX?table=tblXXX
· 知识库表格：https://xxx.feishu.cn/wiki/WikiToken?table=tblXXX
知识库中的表格会自动解析 Wiki Token
数据表 ID，格式：https://xxx.feishu.cn/base/bascnXXX?table=tblXXX

图片上传

开启后会在多维表格中自动上传图片文件（需在表格中添加「图片附件」附件类型字段，并添加 drive:drive 权限）
配置指南
1. 创建飞书应用
打开 https://open.feishu.cn/app → 创建企业自建应用
在「凭证与基础信息」页面获取 App ID 和 App Secret
2. 添加权限
进入应用 → 权限管理 → 搜索并添加：
bitable:app（读写多维表格）
wiki:wiki:readonly（知识库读取，知识库中的表格需要）
drive:drive（云盘文件上传，仅图片上传功能需要）
然后点击「发布版本」并申请权限审批
3. 创建多维表格并添加字段
在飞书中创建一个新的多维表格，添加以下列（字段名需完全一致）：
生成时间、图片链接、来源网页、使用模型
中文提示词、英文提示词、反向提示词
画面描述、风格分析
以上字段类型选择「文本」即可
如果需要上传图片：添加 图片附件 字段，类型选择「附件」
4. 获取 App Token 和 Table ID
打开多维表格，URL 格式为：
· 独立表格：https://xxx.feishu.cn/base/bascnXXX?table=tblXXX
  其中 bascnXXX 是 App Token
· 知识库表格：https://xxx.feishu.cn/wiki/WikiToken?table=tblXXX
  其中 WikiToken 填入 App Token，插件会自动解析
两种 URL 中的 tblXXX 都是 Table ID
5. 授权应用访问表格
在多维表格右上角「...」→ 更多 → 添加机器人 → 搜索并添加你创建的应用
